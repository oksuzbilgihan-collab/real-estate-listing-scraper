# Real Estate Listing Scraper

This project collects public real estate listing data from a website and exports the results into a clean Excel file.

## Project Goal

The goal of this project is to practice web scraping, data extraction, data cleaning, and Excel export for real estate listings.

## Collected Fields

- Listing title
- Location
- Property details
- Price
- Listing date
- Building age
- Floor
- Total floors
- Extra price / dues information

## Tools Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Excel / Google Sheets

## Output

The scraper exports the collected listings into an Excel file.

Example output file:

`output/sample_real_estate_listings.xlsx`


## Notes

This project is created for educational and portfolio purposes.

Only publicly available listing information was used. No private contact information such as phone numbers, emails, or personal data is included in the shared sample file.
